#  Algoritmos de Ordenação

Projeto informativo para demonstrar a diferença de cada algoritmo de ordenação no processamento da mesma base de dados.

##  Estrutura do Projeto

```
src/
├── main.py                    # Ponto de entrada
└── data
    └── data.xlsx              # Dados a serem processados pelos algoritmos
```

##  Algoritmos de ordenação

| Algoritmo    | Total de dados | Fonte de dados |
|------------|----------|------------------------|
| Bubble Sort | 20.000 | [Terrabrasilis – Plataforma de dados geográficos](https://terrabrasilis.dpi.inpe.br/app/dashboard/alerts/biomes/amazonia-nb/daily/) |
| Selection Sort | 20.000 | [Terrabrasilis – Plataforma de dados geográficos](https://terrabrasilis.dpi.inpe.br/app/dashboard/alerts/biomes/amazonia-nb/daily/) |
| Inserction Sort | 20.000 | [Terrabrasilis – Plataforma de dados geográficos](https://terrabrasilis.dpi.inpe.br/app/dashboard/alerts/biomes/amazonia-nb/daily/) |
| Merge Sort | 20.000 | [Terrabrasilis – Plataforma de dados geográficos](https://terrabrasilis.dpi.inpe.br/app/dashboard/alerts/biomes/amazonia-nb/daily/) |
| Quick Sort | 20.000 | [Terrabrasilis – Plataforma de dados geográficos](https://terrabrasilis.dpi.inpe.br/app/dashboard/alerts/biomes/amazonia-nb/daily/) |

## Tecnologias

- **Python 3.10+**
- **TKinter** (GUI)

1. Clone o repositório:
   ```bash
   git clone https://github.com/marcellu-s/APS_Estrutura_de_Dados.git 
   ```
2. Abra o projeto em sua IDE (VS Code, PyCharm, Anaconda).
3. Execute a classe `main.py`.
